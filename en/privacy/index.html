Privacy policy

How this site handles personal information.

What we collect

This is a static website. Simply reading it does not involve the collection of personally identifying information, and there are no user accounts.

If you use the contact form, we receive the name, email address and message you enter.

How it is used

Information from the contact form is used only to reply to your enquiry. It is not repurposed, shared with third parties, or used for advertising.

Server logs

Our hosting provider's servers may retain technical records — access time, IP address, user agent — for a limited period. These are used to operate the site and to guard against abuse.

Cookies

This site uses no advertising or tracking cookies. It may use browser session storage to remember that you have dismissed the language-switch notice. That value is cleared when you close the browser and is never transmitted anywhere.

External links

This site links to external websites. We are not responsible for how those sites handle personal information.

Contact

For questions about personal information, email hello@goodgoodmart.com.

Changes

This policy may be revised as needed.
